# uisight — Security & robustness audit (2026-08-20)

Scope: full repo (`src/cli.mjs` 670, `src/server.mjs` 578, `src/mcp.mjs` 233), package + release health.
Method: 3 parallel review agents (security · robustness/wiring · devex/packaging), each reading the
code rather than guessing; every KRİTİK/YÜKSEK finding then re-verified by hand — the security
findings by running real requests against a live server, the XSS one end-to-end in a real browser.

Two independent security agents were dispatched with overlapping scope. They converged on the same
three critical issues (unintended cross-agent confirmation) and each caught one the other missed —
the reason the XSS finding exists at all.

## Verified sound (no change needed)

- `files` publishes exactly `src/`, both READMEs, LICENSE — runtime artifacts live in `~/.uisight`, outside the package tree.
- Browser‑open `exec()` calls interpolate only internal, sanitized paths — the audited URL never reaches a shell.
- `file://` is unreachable via `goto` (non‑`http(s)` input gets an `http://` prefix and fails) — accidental, but effective.
- CSS selectors run through Playwright's engine, not `eval`.
- SSE `error`/`close` handling, `unhandledRejection`/`uncaughtException` guards, EADDRINUSE message, WebKit→Chromium fallback, per‑record error isolation in the CLI, output path outside `node_modules` — all confirmed working.
- MCP↔server wiring: all 9 tools' payload field names match the server, session map (`desktop→web`, `mobile→mobil`) correct.
- Turkish internals with English surfaces: deliberate, documented in the README — not a defect.

## Known gaps (not fixed here)

- **No tests.** Highest value first: the pure WCAG math in `cli.mjs` (`kanal`/`parlaklik`/`kontrast`/`karistir`) is DOM‑free and testable with `node:test` at zero dependency cost; the DOM‑dependent `DENETIM_KODU` needs a Playwright fixture (gradient text, `oklch`, 44 px targets).
- **No CI.** A single job running `node --check`, `npm pack --dry-run` and the tests above would have caught the publish drift.
- `Promise.race` timeouts don't cancel the underlying CDP call — an orphaned session can linger after a timeout.
- `--watch` relaunches the browser each tick instead of reusing it.
- Registry namespace is personal (`io.github.yusufcemres`) pending [registry#1551](https://github.com/modelcontextprotocol/registry/issues/1551); moves to the org once resolved.
